## 1. 引言

### 1.1 项目背景

Windows 系统在长期使用过程中会累积大量冗余文件、无效注册表项、卸载残留、自启动项与服务，导致磁盘空间被占用、系统启动变慢、运行卡顿。现有市面工具（如 CCleaner、Geek Uninstaller、火绒等）多存在以下问题之一：功能分散需多工具组合、捆绑广告/全家桶、对 UWP/商店应用与残留清理不彻底、文件迁移能力薄弱、缺乏操作回滚机制。

本项目目标是构建一款**轻量、绿色、可回滚、功能一体化**的 Windows 系统优化管理工具，覆盖软件卸载、残留清除、文件迁移、垃圾清理等核心场景。

### 1.2 项目目标

> **品牌口号：看得见、退得回、不联网 —— sysmgr，第一款你敢让父母用的系统优化工具。**
> - "看得见" = 操作全透明 + 性能曲线（持续输出价值）
> - "退得回" = 系统时间机器（终极后悔药）
> - "不联网" = 自我断网（可证明可信）
> - 注：三大卖点均为**行为级可验证**（Wireshark/操作面板/回滚触发即可独立核验），不依赖源码开源——闭源付费模式下仍能维持信任护城河（见 FR-TRUST-04）。

- **功能一体化**：在一个工具内覆盖卸载 / 残留 / 迁移 / 清理 / 启动项管理等高频场景，免去多工具切换。
- **安全可回滚**：所有破坏性操作（删除、迁移、注册表修改）均先备份/记录，支持一键回滚。
- **绿色便携**：提供免安装便携版，不常驻后台服务，不联网收集用户数据。
- **彻底清理**：对常规软件、UWP 应用、商店应用均支持深度残留扫描（注册表、AppData、ProgramData、安装目录）。
- **可观测**：操作前后给出空间释放量、影响项清单，让用户对"做了什么、释放了多少"一目了然。
- **可信透明**：操作全过程可见、可验证、可证明不联网（见 §3.15 TRUST 模块），构建区别于"黑盒清理工具"的信任护城河。
- **软件免费、AI 收费**：所有软件功能永久免费（含价值护城河），仅云端 AI 按 token 付费（见 §9）。此模式让信任护城河在免费层完整兑现，付费点与"不联网"定位天然契合（付费即主动选择联网增强）。

## 2. 总体描述

### 2.1 产品概述

一款运行于 Windows 桌面的系统优化管理工具，以"模块化中心 + 操作回滚引擎"为核心架构，用户在统一界面内使用各功能模块，所有破坏性操作经回滚引擎统一备份与记录。

### 2.2 用户角色

| 角色 | 描述 | 关注点 |
| --- | --- | --- |
| 个人用户 | 普通家庭用户，技术能力一般 | 简单易用、一键清理、释放 C 盘空间 |
| 进阶用户 | 有一定技术背景的开发者/运维 | 可控粒度、可查看明细、命令行/脚本化 |
| IT 管理员 | 企业 IT 运维 | 批量处理、可导出报告、可静默运行 |

### 2.3 运行环境

- **操作系统**：Windows 10 (x64) 及以上，兼容 Windows 11
- **架构**：x64（V1 仅 x64）；ARM64 后续版本视设备市占与用户反馈再评估，V1 不预留构建路径
- **运行时**：.NET 8，单文件自包含发布（不依赖系统预装 Runtime）
- **权限**：需以管理员权限运行（卸载、注册表、服务操作必需）
- **磁盘**：自身占用 ≤ 70MB（便携版，单文件自包含；.NET 8 runtime + WPF runtime 自包含为体积大头，业界 .NET WPF 单文件应用普遍 50-80MB，详见 §3.15.6 FR-CLI-01 与 TDD §8.1 PoC 实测）

### 2.4 假设与约束

- 假设用户对要清理/迁移的内容有最终决定权，工具仅做"建议 + 用户确认 + 执行 + 回滚"。
- 不做任何自动后台调度清理（避免常驻服务，保持绿色定位）。
- **联网白名单（默认全禁，仅以下场景允许，且均需用户手动开启并可在设置中关闭）**：
  1. 用户手动触发"检查更新"时（仅访问 sysmgr 官方更新服务器，HTTPS）。**便携版默认不自动检查，仅手动触发；发现新版仅提示并给出下载链接，不自动下载/安装，保持便携版"零后台联网"定位。安装版/Store 版自动更新由 Store 接管。**
  2. §3.9 弹窗规则库在线更新（仅此一项允许，可在设置中关闭，关闭后仅用内置离线规则）。
  3. §3.15 TRUST-03 自我断网开关的"验证"动作（仅访问一个固定自检端点以证明规则已生效）。
  4. §3.15.8 FR-AI-05 云端增强 AI 调用与 §9.3 AI 钱包余额查询（可选，默认关；仅访问 sysmgr 官方 AI 网关，HTTPS；上传内容为脱敏诊断上下文，严禁含用户文件正文/聊天记录/密码/Cookie/注册表值；用户可关闭，关闭后自动回退本地引擎）。本地模型文件下载（FR-AI-04）也走本项。
  - 除上述四项外，**软件运行期间禁止任何形式的出站网络请求**（不传用户数据、不上报遥测、不下载组件）。如检测到非白名单域名的出站尝试，本地拦截并写入日志、提示用户。
- 文件迁移目标盘符需用户显式指定，不自动迁移到网络盘/可移动盘。

## 3. 功能需求

> 模块设计参考：360 安全卫士（系统盘瘦身 / C 盘搬家 / 大文件查找 / 文件粉碎机 / 开机加速）、火绒安全（垃圾清理 / 弹窗拦截 / 启动项管理）、Geek Uninstaller（强制卸载 / UWP 卸载）、SpaceSniffer（Treemap 磁盘可视化）。

### 3.0 安全等级判定规则（全模块统一口径）

> 多个模块使用"高/中/低安全等级"判定是否默认勾选。本节为判定基准，各模块不得自定义冲突规则。

| 等级 | 判定维度 | 默认行为 | 代表性示例 |
| --- | --- | --- | --- |
| **高（建议处理，默认勾选）** | 路径明确为软件私有残留（卸载后无主文件/注册表项）；不被系统或其他软件引用；可由重装软件或系统机制重建；不在系统关键目录 | 默认勾选，二次确认后执行 | 软件 `%LocalAppData%\<Vendor>` 缓存、卸载后 `Uninstall` 注册表空键、`%TEMP%` 下非占用临时文件、浏览器缓存目录 |
| **中（需人工判断，默认不勾）** | 路径可能被其他软件共用；引用关系不完全确定；删除可能影响个别软件功能但不影响系统启动 | 默认不勾，提示风险后由用户决定 | `%ProgramData%` 下共享配置、`HKLM\SOFTWARE` 下非空 CLSID、共享字体、计划任务中通用触发器 |
| **低（可能影响系统/其他软件，默认不勾且需强确认）** | 位于系统关键路径或被系统服务引用；删除可能导致软件无法启动或系统异常；不可自动重建 | 默认不勾，需展开"高级"并显式勾选 | `C:\Windows\System32` 下文件、`HKLM\SYSTEM\CurrentControlSet` 服务键、`WinSxS` 组件、系统关键服务依赖项 |

**判定流程**：扫描时对每一项依次检查 ①是否在系统关键白名单路径 ②是否被其他已装软件的注册表/快捷方式引用 ③是否可由重装或系统机制重建，综合给出等级。等级可在结果中由用户手动调整（仅上调不下调，避免误删高危项）。

### 3.1 电脑体检（统一入口）

**FR-CHECK-01 一键体检**
- 单击"立即体检"，从垃圾、性能、安全、启动项、磁盘空间五个维度并行扫描，输出健康评分（0-100）与问题清单。
- 每项问题提供"一键修复"按钮，自动跳转到对应功能模块并预勾选处理项。

**FR-CHECK-02 体检项配置**
- 用户可勾选/取消体检项；默认包含：临时文件量、可释放 C 盘空间、启动项过多、长期未用软件、可选卸载项、可清理还原点、休眠文件占用、弹窗规则数等。

**FR-CHECK-03 体检历史**
- 记录历次体检得分，可查看趋势对比。

### 3.2 软件卸载模块

**FR-UNINSTALL-01 软件清单展示**
- 扫描并展示系统中已安装的软件，包含：常规安装软件（注册表 Uninstall 键）、UWP/商店应用、Windows 可选功能/系统组件（可标记为"系统组件"默认折叠隐藏）。
- 每条记录展示：名称、发布者、版本、安装日期、占用大小、安装路径、源（注册表/UWP/MSI）。
- 支持即时搜索（键入即过滤，参考 Geek Uninstaller）、按名称/大小/安装日期排序。
- 长期未用软件采用**复合判定**（不依赖 NTFS Last Access Time，因其默认禁用不可靠）：① Prefetch 最后执行时间（`%SystemRoot%\Prefetch\*.pf` 的最后写入）② 注册表 InstallDate ③ 是否仍存在启动项。三项均无近 90 天活动即标记"长期未用，建议卸载"，阈值可配置默认 90 天。

**FR-UNINSTALL-02 标准卸载**
- 调用软件自身的卸载程序（UninstallString）执行卸载。
- **卸载前检测目标软件进程是否在运行**：若运行中则提示"软件正在运行，请先关闭"，并提供"强制结束进程并继续"开关（默认关，开启后结束主进程及其子进程）。
- 卸载完成后自动触发"残留扫描"（联动 §3.3）。

**FR-UNINSTALL-03 静默卸载（进阶）**
- 对支持静默参数的安装包（如 MSI `/qn`、Inno Setup `/VERYSILENT`、NSIS `/S`）提供静默卸载选项。
- 静默卸载前必须显式二次确认。

**FR-UNINSTALL-04 强制卸载**
- 当软件自带卸载程序损坏或缺失时，提供"强制卸载"：直接清理安装目录 + 注册表项 + 服务 + 计划任务。
- 强制卸载前必须生成完整残留快照并提示用户确认。

**FR-UNINSTALL-05 批量卸载**
- 支持多选批量卸载（顺序执行，单失败不阻塞后续）。

### 3.3 残留清除模块

**FR-RESIDUAL-01 残留扫描**
- 扫描维度：
  - 注册表：`HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*`、`HKCU` 同路径、`HKLM\SOFTWARE\WOW6432Node\...`、软件名相关的 `App Paths`、`Shell Extensions`、`CLSID` 残留。
  - 文件系统：`%ProgramFiles%`、`%ProgramFiles(x86)%`、`%LocalAppData%`、`%AppData%`、`%ProgramData%`、`%PUBLIC%`。
  - 服务与驱动：服务/驱动名包含软件关键词的项。
  - 计划任务：路径或任务名包含软件关键词的任务。
  - 启动项：注册表 Run 键、启动文件夹、对应软件的启动项。
- 扫描结果按"安全等级"分类：高（建议删除）/ 中（需人工判断）/ 低（可能影响其他软件，默认不勾选）。

**FR-RESIDUAL-02 残留清除**
- 用户勾选要清除的项，二次确认后执行。
- 删除前对文件/注册表项生成影子备份（见 §3.13 回滚引擎）。
- 支持仅扫描不删除（dry-run 预览）。

**FR-RESIDUAL-03 软件关联残留**
- 与 §3.2 联动：卸载某软件后自动扫描其残留，并展示"残留项数 + 预计释放空间"。

### 3.4 C 盘瘦身模块

> 聚焦"释放 C 盘空间"这一最高频痛点。整合大文件迁移、休眠/虚拟内存管理、Windows.old、用户文件夹迁移等关键场景。

**FR-CSLIM-01 C 盘占用分析**
- 一键分析 C 盘空间分布，按"系统/保留空间、已安装应用、用户文件、临时文件、其他"分类展示，并标注每类占用大小。
- 与 §3.5 磁盘可视化联动，可下钻到具体目录/文件。

**FR-CSLIM-02 大文件定位与迁移**
- 扫描 C 盘下的大文件（阈值可配置，默认 ≥ 100MB），**排除以下系统关键目录**（默认排除清单，可在设置中查看但默认不可取消）：
  - `C:\Windows\*`（含 `System32`、`SysWOW64`、`WinSxS`、`Installer`、`SoftwareDistribution`、`Recovery`、`Boot`、`WinSxS\Backup`）
  - `C:\Program Files`、`C:\Program Files (x86)` 内系统组件目录
  - `C:\$Recycle.Bin`、`C:\System Volume Information`、`C:\Recovery`
  - `pagefile.sys`、`hiberfil.sys`、`swapfile.sys`
- 展示：文件路径、大小、最后访问时间、文件类型分类（视频/图片/文档/安装包/数据库/其他）。
- 提供"迁移到其他盘"入口，迁移走 §3.7 文件迁移引擎（复制+校验+回滚）。

**FR-CSLIM-03 休眠文件管理**
- 检测 `hiberfil.sys` 大小，提供"关闭休眠释放空间"（执行 `powercfg /h off`）与"启用快速启动但不保留休眠"等选项。
- 关闭前提示用户影响（如关闭快速启动、合盖改睡眠不受影响）。

**FR-CSLIM-04 虚拟内存转移**
- 检测 `pagefile.sys` 位置与大小，引导用户将虚拟内存从 C 盘转移到其他盘（修改注册表 `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management` 下的 `PagingFiles`）。
- 对内存 ≤ 8GB 的设备给出"不要彻底关闭虚拟内存"的风险提示。
- 修改需重启生效，提示用户。

**FR-CSLIM-05 Windows.old 与更新残留清理**
- 检测 `C:\Windows.old`、`C:\Windows\SoftwareDistribution\Download`、`C:\Windows\WinSxS\Backup`、`C:\$WinREAgent`、传递优化文件等更新残留。
- 清理 Windows.old 前提示"将无法回退到上一个 Windows 版本"。

**FR-CSLIM-06 系统还原点管理**
- 列出 C 盘所有还原点及占用空间。
- 操作：保留最近 N 个 / 删除全部（释放空间）/ 调整最大使用量。
- 删除前提示"将无法回退到对应时间点"。

**FR-CSLIM-07 用户文件夹位置迁移**
- 支持将"桌面 / 文档 / 下载 / 图片 / 视频 / 音乐"等用户文件夹从 C 盘迁移到其他盘。
- **不硬编码路径**：源路径从注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders` / `User Shell Folders` 实际读取（兼容用户已自定义目录的情况），目标路径由用户指定后写回注册表并移动文件。
- 迁移过程走文件迁移引擎（§3.7），可回滚。

**FR-CSLIM-08 默认保存路径建议**
- 检测 Windows "新内容保存位置"（设置 → 系统 → 存储 → 高级存储设置），建议用户将新应用、新文档、新图片等默认保存到非 C 盘。
- 不强制修改系统设置，提供"一键应用建议"按钮，由用户确认后修改。

### 3.5 磁盘空间可视化分析模块

> 参考 SpaceSniffer / WinDirStat 的 Treemap 思路，让用户"一眼看到什么在占空间"。

**FR-VIS-01 Treemap 可视化**
- 对选定盘符/目录递归扫描，以矩形面积对应文件/文件夹大小，绘制 Treemap。
- 颜色按文件类型区分（视频=橙、图片=蓝、文档=绿、安装包=红、数据库=紫、其他=灰）。
- 支持鼠标滚轮缩放、双击下钻、后退按钮返回上级。

**FR-VIS-02 筛选与定位**
- 支持按文件名/扩展名/大小阈值/日期/属性筛选。
- 右键菜单：在资源管理器中打开、删除（走回滚）、迁移（走文件迁移引擎）、添加标签。

**FR-VIS-03 标签与导出**
- 支持给文件/文件夹打标签（"待处理"等），便于后续操作。
- 支持将扫描结果导出为快照文件，便于二次查看或传给 IT 协助。

### 3.6 垃圾清理模块

**FR-CLEAN-01 系统临时文件清理**
- 清理范围：`%TEMP%`、`%SystemRoot%\Temp`、`C:\Windows\Prefetch`、缩略图缓存、Windows 错误报告、内存转储、回收站。
- 每项标注"预计释放空间"与"安全等级"。

**FR-CLEAN-02 浏览器隐私清理**
- 支持浏览器：Edge、Chrome、Firefox、Brave、Opera（IE 已退役，不再支持）。
- 可勾选项：缓存、Cookie、历史记录、下载记录、表单数据、密码（默认不勾）。
- 提供"仅清理缓存，保留登录态"的预设。
- **扫描前检测目标浏览器进程是否在运行**：若运行中提示"请先关闭浏览器"，并提供"强制结束浏览器进程"开关（默认关，开启后结束对应浏览器进程再清理，避免清理时文件被占用导致失败）。

**FR-CLEAN-03 注册表清理**
- 扫描无效注册表项：缺失文件引用、空键、无效 CLSID、无效卸载项。
- 清理前自动导出 `.reg` 备份至回滚目录。
- 默认仅扫描"高安全等级"项，避免业界常见的误删问题。

**FR-CLEAN-04 软件缓存清理**
- 内置常见软件（微信、QQ、Chrome、VSCode、IDEA 等）的缓存路径规则集，支持扩展。
- 仅清理"缓存"类目录，不碰用户数据/聊天记录。

**FR-CLEAN-05 重复文件查找**
- 在指定范围内按哈希（先按大小筛选，再算 SHA-256）查找重复文件。
- 提供保留策略建议（保留最新/最旧/最大路径深度），但**不自动删除**，需用户逐项确认。
- 与 §3.5 联动：在 Treemap 中高亮重复文件组。

**FR-CLEAN-06 一键清理**
- "一键清理"按钮：勾选所有"高安全等级"项执行。
- 提供清理前后空间对比与清理报告。

### 3.7 文件迁移引擎

> 通用文件/应用迁移能力，被 §3.4、§3.5 调用。

**FR-MIGRATE-01 文件夹迁移**
- 支持迁移任意指定目录（含子内容），可走目录联接（junction）兼容旧路径引用。
- 迁移步骤：扫描 → 复制 → 校验（SHA-256）→ 创建联接 → 删除原文件，任一步失败可回滚。

**FR-MIGRATE-02 应用迁移（进阶，V2）**
- 将已安装软件从 C 盘迁移到其他盘符，通过迁移安装目录 + 修正注册表路径 + 创建目录联接实现。
- 仅对不依赖绝对路径的软件提供迁移建议，对已知不兼容软件（如杀软、数据库、Office）给出警告清单。
- 迁移前必须强制备份原路径与注册表项。

### 3.8 启动项与服务管理模块

**FR-STARTUP-01 启动项管理**
- 展示并管理：注册表 Run 键（HKLM/HKCU）、启动文件夹、计划任务中的登录触发项、UWP 自启动项。
- 操作：禁用 / 启用 / 删除 / 编辑命令行。
- 修改前备份原值；标注"开机耗时影响"。

**FR-SERVICE-01 服务管理**
- 列出所有系统服务，标注：服务名、描述、状态、启动类型、依赖关系。
- 操作：启动 / 停止 / 禁用 / 设为手动 / 设为自动（延迟）。
- 对"系统关键服务"提供保护清单，禁止禁用（如 RpcSs、WinDefend、WinLogon 等），避免造成系统无法启动。
- 提供"安全优化建议"：仅推荐业界公认可禁用的非关键服务（如远程注册表、Print Spooler 在不打印时等），并标注风险等级。

**FR-SERVICE-02 计划任务管理**
- 列出所有计划任务，标注：任务名、状态、触发器、上次运行、下次运行、路径。
- 操作：禁用 / 启用 / 删除（删除前备份 XML 定义）。

### 3.9 弹窗拦截模块

> 参考火绒"弹窗拦截"招牌功能，是用户高频痛点。

**FR-POPUP-01 内置规则库**
- 内置常见流氓软件/广告弹窗的拦截规则。
- **规则匹配键采用"进程路径 + 窗口类名（ClassName）+ 标题子串"三元组**（不使用 HWND，因句柄每次创建都变，无法持久匹配）。
- 规则库外置为 JSON，可在线更新（仅此一项允许联网，需用户开启，见 §2.4 联网白名单）。
- **执行机制用事件驱动而非轮询**：通过 `SetWinEventHook` 监听 `EVENT_OBJECT_CREATE` / `EVENT_OBJECT_SHOW`，新窗口出现即回调匹配规则，命中则 `PostMessage(WM_CLOSE)` 或 `TerminateProcess`（按规则配置），避免轮询占用 CPU。

**FR-POPUP-02 自定义拦截**
- 提供"截图拦截"：用户在弹窗出现时拖拽选区截图，工具通过 `WindowFromPoint` 反查窗口并自动提取"进程路径 + 类名 + 标题"三元组加入规则（不存句柄）。
- 提供"窗口记录"：开启后记录所有出现的窗口三元组与时间戳，便于回看快速闪过的弹窗并加入规则。

**FR-POPUP-03 规则管理**
- 用户可查看/编辑/删除规则，支持"误拦截"白名单（白名单按进程路径匹配，命中白名单的窗口永不被拦截）。
- 拦截记录可查询、可导出。

### 3.10 文件粉碎模块

**FR-SHRED-01 强制删除**
- 对"文件被占用、权限不足、路径过长、只读"等无法常规删除的文件提供强制删除。
- **支持目录粉碎**：递归删除整个目录树（含只读/隐藏文件），删除前展示目录内文件数与总大小供确认。
- 删除前可选"先结束占用进程"。

**FR-SHRED-02 多遍覆写**
- 提供"快速粉碎（1 遍零写）"与"安全粉碎（3 遍/7 遍覆写，参考 DoD 标准）"两档。
- 粉碎后不可恢复（不走回滚，明确提示）。

**FR-SHRED-03 右键集成**
- 可选安装资源管理器右键菜单"用 sysmgr 粉碎"。
- **仅安装版可用**：便携版不写注册表右键菜单项（保持便携版零残留特性）；便携版用户可在主界面手动拖入文件粉碎。

### 3.11 系统优化模块

**FR-OPT-01 系统设置优化**
- 提供预设配置：性能优先（关闭不必要视觉效果）、性能平衡（默认）、外观优先。
- 可调项：视觉效果、电源计划（在高性能/平衡/节能间切换，可恢复默认）、关闭 SysMain/Superfetch（针对 SSD）、关闭 NTFS 最后访问时间戳等，每项标注影响与风险。

**FR-OPT-02 网络优化**
- DNS 优选（一键切换到公共 DNS 如 114/阿里/Cloudflare，可恢复默认）。
- TCP 接收窗口自动调优开关、关闭/启用 RSC。
- 不做"网络加速"夸大宣传，仅做客观设置调整。

**FR-OPT-03 内存优化（轻量）**
- 提供"一键释放内存"：通知系统 Standby List 写回、清理工作集（仅对未在前台的进程）。
- 不常驻后台，按需触发。

### 3.12 系统信息与监控模块（轻量）

**FR-MONITOR-01 系统概览**
- 展示：CPU/内存/磁盘实时占用、各盘符空间使用情况、系统开机时长、关键硬件信息。
- 不做后台常驻监控，仅在界面打开时实时采样。

**FR-MONITOR-02 操作报告**
- 每次操作后生成报告：操作类型、影响项数、释放空间、耗时、是否成功、回滚标识。
- 历史报告可查询、可导出（CSV/HTML）。

### 3.13 回滚引擎（横切关注点）

**FR-ROLLBACK-01 操作快照**
- **除文件粉碎（不可回滚）外，其他破坏性操作（删除文件、删除注册表项、修改服务、迁移等）执行前均自动生成快照**：
  - 文件：复制到回滚目录 `<DataDir>\Rollback\<OpId>\`
  - 注册表：导出为 `.reg` 文件
  - 服务/启动项配置：序列化为 JSON
- **大文件回滚策略**：单个文件超过阈值（默认 500MB）时不复制原文件，改用以下之一：① NTFS 卷影副本（VSS）创建快照点，回滚时从卷影恢复；② 仅记录原路径 + SHA-256，回滚时如文件仍在原位置且校验通过则直接恢复，否则标记"原文件已不存在，仅恢复路径占位"。阈值可在设置中调整。
- 快照元数据：操作 ID、时间、操作类型、原值、目标值、关联模块、文件大小、回滚策略标记。

**FR-ROLLBACK-02 回滚执行**
- 在"历史与回滚"界面选择某次操作，一键回滚。
- 回滚前校验目标环境未发生冲突（如目标路径已被新文件占用）。
- 回滚完成后保留快照直至用户手动清理或超过保留期。

**FR-ROLLBACK-03 回滚空间管理**
- 回滚目录可配置位置与大小上限。
- **保留策略为"1GB 或 14 天，先到先清"**：单次操作快照超过 1GB 或保留超过 14 天任一条件先到即触发 LRU 清理，避免重蹈"清理工具自己塞满 C 盘"。

**FR-ROLLBACK-04 回滚失败兜底**
- 当回滚执行失败（目标路径冲突、权限不足、原文件损坏等）时，不得静默放弃，执行以下兜底流程：
  1. 在回滚目录下生成 `rollback_failed_<timestamp>.txt` 报告，列出：操作 ID、失败项清单、原快照路径、SHA-256、目标路径、失败原因。
  2. 将报告同时复制一份到用户桌面并标记"待人工恢复"。
  3. 在主界面"历史与回滚"中标记该操作为"回滚失败 - 需人工介入"，并提供报告打开入口。
  4. 保留对应快照不被 LRU 清理，直至用户手动确认。

### 3.14 设置与帮助

**FR-SETTINGS-01 全局设置**
- 语言、主题（浅色/深色/跟随系统）、回滚目录与保留期、扫描阈值、排除路径、规则库更新策略。
- 是否开启遥测（默认关闭，仅本地匿名统计，不联网）。
- **AI 钱包管理入口**：查看钱包余额、充值、查看 token 用量明细、查看/购买套餐、登录/退出账号（联网走 §2.4 白名单第 4 项）。
- **AI 辅助入口（免费）**：开启/关闭 AI 入口、选择推理引擎（规则引擎 / 本地大模型 / 云端增强）、管理本地模型文件、查看/编辑/清除 AI 上下文记忆、查看 AI trace 日志、云端增强开关（默认关，走 §2.4 白名单第 4 项；云端调用按 token 计费见 §9.2）。

**FR-SETTINGS-02 帮助**

### 3.15 增强能力模块（竞争力护城河）

> 以下 7 组能力构成 sysmgr 区别于同类工具的护城河，按推荐版本分配（V1/V1.5/V2/V3）。每条竞争力转化为 1-3 条 FR，编号前缀对应其主题。

#### 3.15.1 操作全透明 + 自我断网（V1 MVP，信任护城河）

**FR-TRUST-01 操作直播日志面板**
- 主界面常驻一个可展开的"操作直播"面板，实时滚动展示所有正在/已执行动作的：命令、目标路径、原值→目标值、耗时、状态。
- 日志同时落盘到本地文件（JSON Lines 格式），可回放。
- 面板支持"暂停滚动 / 清屏 / 导出"。

**FR-TRUST-02 操作前预演**
- 任何破坏性操作执行前，先弹出"将执行的命令清单"预览（逐项列出会删什么、改什么、影响什么），用户审核后才真正执行。
- 预演清单可导出为文本，便于用户或 IT 留档。

**FR-TRUST-03 自我断网开关**
- 主界面提供一键"自我断网"开关：开启后给自身程序添加 Windows Firewall 出站阻断规则（按程序路径匹配），并立即生效。
- 开启后弹窗自检：访问一个固定自检端点（见 §2.4 联网白名单第 3 项）验证规则已生效，面板显示"已断网验证通过"。
- 关闭开关即移除该 Firewall 规则，恢复联网（仅检查更新/规则库更新场景）。

**FR-TRUST-04 操作日志格式公开 + 第三方审计 + 行为级可验证**
- ~~开源核心~~（已确认闭源，不再开源）。改为以下三层信任证据，弥补无源码可查的信任缺口：
  1. **操作日志格式公开文档化**：FR-TRUST-01 落盘的 JSON Lines 日志格式对外公开，第三方可写解析工具离线核验 sysmgr 行为。
  2. **第三方安全审计**：每个大版本发布前委托独立第三方做安全审计（行为白盒/网络抓包/权限范围），出具审计报告并公开摘要。
  3. **行为级可验证**：用户可用 Wireshark/-netstat 自行验证"自我断网开关"开启后确无出站流量；操作直播面板可见每一步动作；回滚可触发验证。三大卖点（不联网/看得见/退得回）均不依赖源码即可被用户独立验证。

#### 3.15.2 系统时间机器（V1.5 起做变更对比+性能曲线，V2 做完整时间机器，价值护城河）

**FR-TM-01 定期自动配置快照**
- 默认每周一次（可改为每天）对"注册表关键节点 + 启动项 + 服务配置 + 已装软件清单 + 系统设置（视觉效果/电源/DNS 等）"做**轻量配置快照**（不快照文件，避免占用磁盘）。
- 快照存于 `<DataDir>\Timeline\<YYYYMMDD>\`，含可读 JSON 与对比索引。

**FR-TM-02 变更对比**
- 选两个时间点，可视化展示"这段时间装了什么、删了什么、改了哪些启动项、新增/禁用了哪些服务、改了哪些系统设置"。
- 差异项可一键跳转到对应模块处理。

**FR-TM-03 任意时间点配置回滚**
- 不只是单次操作回滚，而是支持"回到 3 天前/上周一的系统配置"：选定历史快照后，将上述配置维度整体回滚到该时间点状态（文件不动）。
- 回滚走 §3.13 引擎，先对当前配置做快照再回滚（保证可再回滚回来）。

**FR-TM-04 性能基准曲线**
- 定期跑轻量基准（开机时长、CPU 空闲率、磁盘响应时间、C 盘可用空间），画趋势曲线。
- 用户可看到"过去 30 天系统变快还是变慢"，配合变更对比定位性能退化元凶。

#### 3.15.3 反捆绑实时守卫（V2，差异化痛点）

**FR-GUARD-01 安装行为实时监控**
- 监控新软件安装过程，发现未经用户同意的捆绑安装（静默拉起其他安装包、隐藏 EULA 同意框）立即拦截并提示用户。

**FR-GUARD-02 捆绑关系图谱**
- 对每个已装软件，可视化展示"它带了多少附属物（捆绑软件、任务、服务、启动项），各自做什么、占用多少"。

**FR-GUARD-03 一键拒绝所有捆绑**
- 检测到捆绑时，提供"全部拒绝/逐项选择"按钮，仅保留用户明确要装的主软件。

**FR-GUARD-04 流氓行为评分**
- 基于"偷偷加启动项、隐藏窗口、改浏览器主页、外联可疑域名、捆绑安装"等行为给软件打 0-100 分（越高越流氓），并在卸载列表中标注。

#### 3.15.4 软件画像（V1.5 做依赖图谱+卸载预演，智能化护城河）

**FR-PROFILE-01 软件依赖图谱**
- 可视化展示"A 装了之后 B/C/D 跟着装了"的依赖关系（基于安装时间顺序 + 共享厂商 + 注册表引用推断）。

**FR-PROFILE-02 卸载预演**

**FR-PROFILE-03 使用频率画像**
- 基于 Prefetch + 进程启动记录，给"过去 90 天从未打开"的软件打"建议卸载"标，并展示真实使用频率。

**FR-PROFILE-04 变化溯源**
- 用户报告"昨天卡了"，工具自动对比 24 小时内系统变化（新装软件/新启动项/服务变更/磁盘空间骤降），定位元凶。

#### 3.15.5 家庭多机远程管理（V3，场景护城河）

**FR-FAMILY-01 家庭设备列表**
- 绑定多台 Windows 设备（需双方均安装 sysmgr 并显式授权配对，支持局域网直连或云端中转）。

#### 3.15.6 便携 + 命令行版（V1 MVP 做便携，V1.5 做命令行，口碑护城河）

**FR-CLI-01 真·单文件便携版**
- 便携版打包为单一可执行文件（目标 ≤ 70MB，单文件自包含 .NET 8 + WPF runtime），U 盘即插即用，运行时不写注册表、不安装服务、退出后不留痕。
- **体积约束依据**：TDD §8.1 PoC 实测（2026-09-28）最小脚手架（5 项目 + WPF-UI 4.3.0）单文件自包含发布 = 65.21MB；体积大头为 .NET 8 runtime + WPF runtime 自包含（~50MB+），非 sysmgr 代码或 WPF-UI 开销。原 ≤ 8MB 目标在 .NET + WPF 技术栈下不可达（C++ 原生工具可达，但 §5.1 已定稿不可推翻），故放宽至 ≤ 70MB，对齐业界 .NET WPF 单文件应用区间。保持"单文件 + 不依赖预装 Runtime + 便携零残留"三大核心承诺不变。

**FR-CLI-02 sysmgr-cli 命令行版**
- 提供 `sysmgr-cli` 支持子命令：`clean`（垃圾清理）、`uninstall <name>`（卸载）、`scan`（扫描）、`rollback <opid>`（回滚）、`timeline diff`（变更对比）等，可脚本化、可静默运行（供 IT 管理员批量使用）。

**FR-CLI-03 配置文件即代码**
- 规则集 YAML 化，进阶用户可版本控制（Git 管理）、分享、复用。

**FR-CLI-04 右键菜单"用 sysmgr 分析"**
- 任意文件夹右键调出 Treemap 分析（仅安装版）。

#### 3.15.7 游戏模式 + 硬件健康（V2 游戏模式，V1.5 做 S.M.A.R.T.，场景化护城河）

**FR-GAME-01 真·游戏模式**
- 一键关闭非关键服务/后台进程、暂停 Windows 更新（暂停期内）、清 Standby List、暂停弹窗拦截规则（避免游戏时弹拦截提示），游戏退出后自动恢复。

**FR-HW-01 SSD 健康**
- 读取 S.M.A.R.T. 数据：剩余寿命预测、TRIM 状态、写入放大估算、温度，异常时预警。

**FR-HW-02 游戏 mini HUD**
- 游戏运行时可在屏幕角落调出温度/帧率/CPU 占用悬浮窗（仅显示，不录制）。

**FR-HW-03 游戏性能基准**
- 装某游戏前后跑帧率基准，对比"是否被后台进程拖累"。

#### 3.15.8 AI 辅助模块（V3 起做，本地优先 + 云端可选，智能化护城河）

> **设计哲学**：AI 必须服从"不联网"信任定位——默认全本地推理（on-device），不传用户数据；仅在用户显式开启"云端增强 AI"时才走受限联网通道（纳入 §2.4 联网白名单第 5 项），且上传内容为脱敏后的诊断上下文（不含用户文件正文/聊天记录/密码）。AI 的所有"执行类"输出都落地为结构化操作计划，强制走 §3.13 回滚引擎 + TRUST-02 操作前预演，AI 永不直接执行破坏性动作——它只生成"建议清单"由用户审核确认。

**FR-AI-01 自然语言指令入口**
- 用户可用自然语言下达指令，例如：
  - "帮我把 C 盘里超过 1GB 的视频挪到 D 盘" → 解析为 §3.4 FR-CSLIM-02 大文件迁移（视频类、≥1GB、目标 D 盘）
  - "卸载掉那些我三个月没打开过的软件" → 解析为 §3.2 卸载 + PROFILE-03 使用频率画像（90 天未用）
  - "为什么最近电脑这么卡" → 解析为 §3.1 体检 + TM-02 变更对比（最近 7 天）+ PROFILE-04 变化溯源
- 解析流程：本地 NLU（见 FR-AI-04）→ 意图分类 → 实体抽取（软件名/路径/阈值/时间）→ 生成结构化操作计划（JSON Schema）→ TRUST-02 预演面板展示 → 用户确认后执行。
- **歧义澄清**：解析置信度 < 阈值（默认 0.7）或检测到歧义（如"那个软件"指代不明）时，AI 反问澄清而非擅自猜测执行；破坏性意图永远反问一次再执行。
- **安全护栏**：AI 生成计划中若包含 §3.0 低安全等级项或系统关键路径，强制降级为"仅展示不建议执行"，需用户手动展开高级模式逐项勾选。

**FR-AI-02 智能诊断对话**
- 基于已有数据（TM-02 变更对比 + PROFILE 软件画像 + TM-04 性能曲线 + MONITOR 系统概览）主动诊断"系统为什么变慢/变卡/空间不够"并给出可执行修复建议。
- 对话式多轮交互：用户可追问"那 X 软件能卸吗"，AI 结合 PROFILE-02 卸载预演回答"卸它会同时影响依赖它的 Y、Z，释放 1.2GB，建议保留或一起卸"。
- 诊断结论附带"证据链"：列出引用了哪几次配置变更、哪几个软件的画像数据，可点击跳转核验（呼应 TRUST 透明原则）。

**FR-AI-03 操作建议与预警**
- 扫描完成后 AI 生成"建议处理清单"（按 风险×收益 排序），每条用自然语言解释：
  - 为什么建议（"这是 X 软件卸载后遗留的 234 个注册表项，无人引用"）
  - 影响什么（"释放 8MB，不影响其他软件"）
  - 风险等级（呼应 §3.0）
- 对破坏性操作用自然语言生成"影响摘要"："此操作将删除 12 个文件、修改 3 个注册表项，依赖此软件的 A、B 将无法启动"，再走 TRUST-02 预演。
- **反忽悠护栏**：AI 不得使用夸大话术（"极大提升速度""彻底根治"），仅陈述客观可量化影响；话术模板受控，违例告警。

**FR-AI-04 本地优先推理引擎（on-device）**
- **默认全本地推理，不联网**，符合"不联网"信任定位。
- 技术实现（双引擎可切换）：
  1. **规则 + 意图分类引擎（轻量默认）**：基于正则 + 关键词 + 意图分类器（本地小模型，如量化后的 BERT/MiniLM 跑 ONNX Runtime，CPU 推理），覆盖高频指令模式；包内自带，体积增量 ≤ 50MB。
  2. **本地大模型引擎（进阶可选）**：支持加载用户本地的量化小模型（Phi-3-mini / Qwen2.5-3B 量化版等，通过 llama.cpp / ONNX Runtime 跑 CPU/GPU），处理复杂诊断对话；模型文件由用户自行提供或从官方下载（下载走 §2.4 联网白名单第 5 项，可选）。
- 本地引擎加载即用，不强制联网；用户可在设置中关闭 AI 入口（关闭后不影响其他所有功能）。

**FR-AI-05 云端增强 AI（可选，默认关）**
- 用户显式开启后，可调用云端大模型处理本地引擎置信度不足的复杂诊断/多轮对话。
- **严格数据脱敏**：上传内容仅限"诊断上下文"（系统配置摘要、软件清单名、性能指标数值、变更 diff），**严禁包含**：用户文件正文、聊天记录、浏览器历史、密码、Cookie、注册表值内容、文件路径中的用户名（脱敏为 `<USER>`）。
- 纳入 §2.4 联网白名单第 5 项：仅访问 sysmgr 官方 AI 网关（HTTPS），可关闭，关闭后自动回退本地引擎。
- 云端响应同样落地为结构化操作计划，仍走 TRUST-02 预演 + 用户确认，云端不直接执行任何操作。

**FR-AI-06 上下文记忆与偏好学习**
- 本地存储用户偏好记忆：如"别动我的游戏存档目录""微信缓存别清"等禁令，AI 后续操作自动避开并提示"已按你的偏好跳过 X"。
- 记忆数据：本地 KV + 轻量向量检索（用于自然语言召回相关禁令），存于 `%LocalAppData%\sysmgr\ai_memory\`，可查看/编辑/清除，绝不联网。
- 偏好学习仅基于本地交互历史，不做跨用户画像聚合。

**FR-AI-07 AI 行为可审计**
- 每次 AI 解析与建议均落盘到 `ai_trace.jsonl`（含输入原文、解析意图、置信度、生成的操作计划、用户是否采纳、最终执行结果），格式公开（呼应 TRUST-04）。
- 用户可在"历史与回滚"中查看 AI trace，回溯"AI 当时建议了什么、我同意了什么、实际执行了什么"。
- 第三方可写解析工具核验 AI 行为是否越界（如是否触发了破坏性动作而未经确认）。

**FR-AI-08 AI 钱包与计费（唯一营收机制）**
- **钱包账户**：用户注册账号后获得 AI 钱包，余额以 token 计；钱包余额可离线缓存（仅余额数值，不可离线消费），云端调用前必须联网校验余额。
- **充值与套餐**：支持按量充值（预付费到账）与套餐购买（包月/包年，比按量优惠）；套餐到期后剩余按量余额继续可用；具体单价与套餐档位为后续设计阶段定，不在本 SRS 范围。
- **实时计费**：每次云端 AI 调用前预估"本次预计消耗 X token + 当前余额"，调用后按实际输入/输出 token 扣费并展示"实际消耗 Y token / 余额 Z"；余额不足时拒绝调用并提示充值，自动回退本地引擎（不影响其他免费功能）。
- **计费明细**：全量计费明细（时间、调用类型、输入/输出 token、扣费、余额、套餐抵扣）落盘到 `ai_billing.jsonl`，可查询、可按月汇总、可导出 CSV；呼应 TRUST 透明原则。
- **试用额度**：新用户注册赠送 10 万 token 免费额度（约数十次复杂诊断），用完前提示充值，不强制、不弹窗阻断。
- **防欺诈与限流**：网关侧对异常调用模式（短时高频、刷量）做限流与风控，涉嫌滥用可临时冻结钱包并通知用户申诉。
- **退款与申诉**：因网关故障导致的失败调用不计费；用户可对争议扣费提交申诉，申诉处理流程与时效为后续设计阶段定。

> 实现优先级：V3 先落 FR-AI-01/04/06/07（本地闭环 + 审计），FR-AI-05 云端增强 + FR-AI-08 钱包计费作为**营收层同步落地**（云端 AI 是唯一付费点，钱包基础设施必须与云端 AI 同批上线，不可后置），FR-AI-02/03 随 PROFILE/TM 数据成熟度跟进。FR-AI-05/08 上线前需经 §8 的"AI 联网与数据脱敏"专项安全评审。

## 4. 非功能需求

### 4.1 性能
- 软件清单扫描 ≤ 3 秒（千个软件量级）。
- 垃圾清理扫描 ≤ 10 秒（百万级临时文件）。
- 残留扫描 ≤ 5 秒（单软件）。
- 大文件扫描：1TB 数据 ≤ 60 秒（仅遍历不哈希）。
- **本地 AI 推理**：单次自然语言指令解析首 token ≤ 2 秒（CPU 模式，规则引擎+量化小模型），不阻塞主线程（后台推理 + 进度提示）。
- **云端 AI 调用**：首 token ≤ 3 秒（含网络往返），超时 10 秒自动降级本地引擎并提示。

### 4.2 安全性
- 所有破坏性操作默认勾选"高安全等级"项，中/低等级默认不勾选。
- 系统关键路径白名单：`C:\Windows\System32`、`C:\Windows\SysWOW64`、注册表 `HKLM\SYSTEM\CurrentControlSet` 等关键节点默认不可清理。
- 强制卸载、静默卸载、服务禁用均需二次确认。
- 不获取、不上传任何用户隐私数据。

### 4.3 可靠性
- 单操作失败不影响其他操作（隔离执行）。
- **破坏性操作全局串行化**：所有破坏性操作（删除/迁移/注册表修改/服务变更/粉碎）经全局队列串行执行，避免并发导致快照冲突、文件占用、回滚错乱；非破坏性扫描类操作可并行。
- 程序异常崩溃时，未完成的破坏性操作自动回滚或标记为"待回滚"。
- 回滚快照采用事务式写入（先复制后删除）。

### 4.4 易用性
- 一级功能 ≤ 3 次点击可达。
- 关键操作前明确提示风险与影响项数量。
- 支持深色模式与高 DPI。

### 4.5 可维护性
- 模块化架构：各功能模块独立、通过回滚引擎统一调度。
- 软件白名单/黑名单/规则集外置为 JSON/YAML，便于更新无需重新编译。
- 日志分级（DEBUG/INFO/WARN/ERROR）写入本地文件，便于排障。

### 4.6 兼容性
- Windows 10 1809+ / Windows 11。
- **架构：V1 仅 x64**；ARM64 后续版本视设备市占与用户反馈再评估，V1 不预留构建路径。
- 同时提供便携版（免安装）与安装版。
- **界面语言：仅中文（V1）**。文案采用 i18n 可扩展架构（资源文件外置），V1 仅交付中文资源；海外多语言视后续版本反馈再评估，不在 V1 范围内。
- **更新通道**：安装版/Store 版自动更新由 Store 接管；便携版内置"手动检查+提示下载"（不自动下载安装，保持零后台联网）。

### 4.7 AI 网关与钱包可用性（V3 营收层）

> AI 网关与钱包是 V3 唯一营收基础设施，其可用性直接关系收入与口碑，需独立非功能约束。

- **网关可用性**：sysmgr 官方 AI 网关目标可用性 ≥ 99.5%（月度），故障时客户端自动降级本地引擎并提示"云端不可用，已切本地"，不阻断用户工作流。
- **钱包一致性**：扣费必须与网关侧账本最终一致（最终一致性，允许短时偏差但需对账修正）；客户端缓存余额与网关侧权威余额偏差时以网关为准。
- **降级路径**：网关故障 / 钱包校验失败 / 余额不足 三种场景均需自动降级本地引擎，且本地 AI 与全部软件功能不受任何影响（云端 AI 是增强项非必需项）。
- **计费透明**：每次调用前后必须向用户展示 token 消耗与余额（FR-AI-08），全量明细可查可导出（呼应 TRUST-04 行为级可验证）。
- **数据脱敏可审计**：脱敏规则版本化、每次上传 payload 的脱敏前后快照可导出（仅用户自己可查，便于自证未泄露隐私）。

## 5. 技术架构（已确认方案）

### 5.1 技术选型（已确认）

- **技术栈**：C# (.NET 8) + WPF + [WPF-UI](https://github.com/lepoco/wpfui)（Fluent / Modern 风格 UI 库）
- **发布方式**：单文件自包含（self-contained, single-file），不依赖用户预装 .NET Runtime
- **架构形态**：x64，未来视需求评估 ARM64
- **选型理由**：
  - C# 对 Windows 系统 API（注册表 `Microsoft.Win32`、WMI `System.Management`、服务 `System.ServiceProcess`、计划任务 `Microsoft.Win32.TaskScheduler`、UWP 卸载 `Windows.Management.Deployment`）调用成本最低。
  - WPF + WPF-UI 兼顾原生渲染性能与现代 Fluent 视觉风格。
  - 单文件自包含发布可同时满足便携版与安装版的体积需求。

| 候选方案 | 结论 |
| --- | --- |
| C# + WPF + WPF-UI | ✅ 采用 |
| C# + WinUI 3 | ❌ 部署较重、生态仍在演进 |
| Flutter | ❌ 系统层需大量 FFI/原生插件，开发成本高 |
| Tauri / Electron | ❌ 不符合轻量定位 |

### 5.3 数据存储

**数据文件清单**（覆盖全部模块，含新增竞争力）：

| 路径 | 用途 | 可清理 | 含敏感信息 |
| --- | --- | --- | --- |
| `%LocalAppData%\sysmgr\config.json` | 全局配置（设置、阈值、白名单） | 否（用户主动重置才删） | 否 |
| `%LocalAppData%\sysmgr\logs\*.log` | 运行日志（DEBUG/INFO/WARN/ERROR） | 是（保留 7 天） | 否（不含用户文件内容） |

## 8. 风险提示

- **应用迁移 / 强制卸载**为高风险操作，即便有回滚也可能影响软件可用性，需在 V1 文案与确认机制中充分提示。
- **注册表清理**业界争议较大，建议默认仅扫描"高安全等级"项，避免误删导致系统问题。
- **服务禁用白名单**需持续维护，避免误禁关键服务导致无法开机。
- **系统时间机器快照仅配置不快照文件**（FR-TM-01），避免重蹈"清理工具自己塞满 C 盘"的覆辙；回滚快照也走"1GB/14天先到先清"（FR-ROLLBACK-03）。
- **反捆绑守卫需驱动级监控**（minifilter/ETW，FR-GUARD-01），V2 才做但 V1 阶段就要开始技术验证，避免到 V2 才发现兼容性/稳定性问题。
- **家庭多机远程管理（FR-FAMILY）需严格授权设计**：必须双方显式配对授权，避免被滥用为"远程控制木马"；V3 落地前需做安全评审。
- **闭源后规则集不公开**（已确认闭源付费）：规则集作为商业资产保留，不再有社区贡献通道；但弹窗/缓存路径规则仍需持续维护，需建立内部规则审核机制防止误规则；用户可通过 FR-POPUP-03 自定义规则弥补内置规则的覆盖盲区。
- **自我断网开关（FR-TRUST-03）**需确保 Firewall 规则按程序路径精确匹配，避免误伤其他程序；规则失败需有降级提示而非静默。
- **V1.5 移入项的高风险**（休眠/虚拟内存/用户文件夹迁移）必须强制"执行前自动创建系统还原点 + 二次确认 + 失败自动回滚"三重防护，单独做 V1 会风险过载。
- **AI 联网与数据脱敏（FR-AI-05）专项风险**：云端增强 AI 是"不联网"信任定位的最大例外，落地前需经专项安全评审：① 脱敏规则需自动化测试覆盖（断言上传 payload 不含用户文件正文/聊天记录/密码/Cookie/注册表值/用户名）；② 上传前本地展示"将上传的诊断上下文"全文供用户预览确认（不可默认勾选自动上传）；③ 网关侧承诺不留存/不训练；④ AI 生成的一切操作计划必须走 TRUST-02 预演，云端不得绕过用户确认直接执行。**AI 永不直接执行破坏性动作**是硬约束，违例即视为安全漏洞。
- **AI 误判风险**：本地引擎置信度不足时可能误解析意图（如"清理缓存"误判为"删除整个目录"），靠 FR-AI-01 歧义反问 + FR-AI-01 安全护栏（低安全等级强制降级为仅展示）+ TRUST-02 预演三重兜底；FR-AI-03 反忽悠护栏限制话术，避免 AI 诱导用户执行高风险操作。
- **AI 钱包与计费风险（FR-AI-08，V3 营收层）**：钱包是唯一营收机制，风险需专项管控：① 余额篡改——客户端缓存余额仅作展示，扣费权威以网关侧账本为准，防止本地篡改余额白嫖；② 重复计费——网络重试需幂等（同一请求 ID 只计一次），失败调用不计费；③ 套餐边界——套餐与按量余额抵扣顺序需明确并展示给用户，避免争议；④ 申诉与退款——需有可追溯的申诉流程，争议扣费可回滚（账本回写 + 明细标注）；⑤ 钱包账号安全——账号盗用涉及金钱损失，需强认证（二次验证）与异常登录告警。上线前需经专项安全评审与对账机制压测。
- **闭源与信任护城河的张力（已大幅化解）**：已确认完全闭源，但商业模式调整为"**软件全功能免费 + 仅云端 AI 按 token 付费**"后，信任张力大幅化解——软件全部功能（含时间机器/反捆绑/画像/游戏/多机/本地 AI）永久免费，"看得见+退得回+不联网"在免费层完整兑现，唯一付费点云端 AI 本身就是"主动选择联网增强"的场景，付费即承认联网，与"不联网"定位不再冲突。仍需缓解的闭源张力：① FR-TRUST-04 三层证据（日志格式公开 + 第三方审计 + 行为级可验证）；② V1 发布即同步公开"行为级验证指南"（教用户用 Wireshark/netstat 自测断网、查看操作面板、触发回滚）；③ 永不降级承诺——已免费功能永不改为收费，云端 AI 是唯一付费点且永不扩展到其他功能（见 §9.3）。

- **本地优先**：默认本地引擎处理，仅当本地置信度不足且用户确认"用云端增强"时才调用云端并计费；用户可在设置中关闭云端增强（关闭后纯本地、零成本、零联网）

### 9.3 钱包与计费机制要点

- **AI 钱包校验联网**：仅云端 AI 调用与钱包余额查询时联网（走 §2.4 联网白名单第 4 项），其他场景零联网；钱包余额可离线缓存，离线时云端 AI 不可用、本地 AI 与全部软件功能不受影响。
- **离线降级**：无网络或钱包校验失败时，云端 AI 自动降级为本地引擎，不弹窗阻断用户工作流，提示"云端不可用，已切本地"。
- **便携版 AI 钱包**：便携版同样支持云端 AI 付费（钱包绑定账号而非设备），便携版按需联网调用云端 AI（纳入联网白名单）。
- **永不降级承诺（扩展）**：已发布的免费功能不得在后续版本改为收费；云端 AI 是唯一付费点且永不扩展到其他功能；本地 AI 永久免费。
- **数据脱敏前置**：云端 AI 调用前必须经 §3.15.8 FR-AI-05 的脱敏规则与用户预览确认（见 §8 AI 风险），脱敏后内容才计入 token 计费。

> 注：本节为商业模式定稿原则，具体 token 单价、套餐档位、钱包/网关实现、账号体系为后续设计阶段细化，不在本 SRS 范围。商业模式已与 §6 版本规划对齐——V1/V1.5/V2 落地的全部软件功能永久免费，V3 云端 AI（FR-AI-05）为唯一付费点。
